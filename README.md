# RemoteSensing_final_exam_preparation

《**遥感**》（遥感原理 / 遥感导论）期末复习用的 **豆包 AI 刷题助教** 技能包。

导入豆包后，它会**按本课题型出题考你**（名词解释、填空、选择、判断、简答、论述、计算、整卷）、**按采分点批改给分**（指出你漏了哪个关键词）、**讲重点**（一句话本质 → 必背定义 → 为什么 → 怎么考怎么答 → 易错在哪）。

（手机端豆包操作太麻烦；想翻全量考点就看 `02 遥感考点知识库.md`）

> 适用：《遥感》课程期末复习。整理依据：本课 11 个课件（第 2、3、4、5 章 + 第 6 章四节 + 第 7、8 章）＋ 两篇配套论文（黑体辐射、缨帽变换）。

## 3 分钟装好

### 方式：指令 + 仓库链接（最简单）

打开 [豆包](https://www.doubao.com)，建立新的对话，选择**工作模式**，把这个仓库链接甩给豆包，然后对她说：**"豆姐，你给我拉取这个仓库，我要给你装这个 skill 技能包"**，然后按提示选就行了。

### 备选一：指令 + 知识库（推荐，效果最好）

1. 打开 [豆包](https://www.doubao.com)，找到「**创建智能体 / 创建我的 AI**」。
2. **名称**：`遥感期末助教`　**简介**：`会出题、会批改、会讲重点的遥感原理复习助教`
3. 把 `01 豆包指令（粘贴到智能体）.md` 里 **「=== 指令开始 ===」到「=== 指令结束 ===」之间** 的内容，整段粘贴进「**指令 / 人设与回复逻辑**」框。
4. 把 `02 遥感考点知识库.md`（或同内容的 `.txt`）上传到「**知识库 / 文件**」。
5. 保存 → 开始对话，发一句：**`开始吧，先给我菜单`**。

### 备选二：智能体没有知识库入口

按上面第 3 步建好智能体后，进对话把 `02 遥感考点知识库.md` 分 2–4 条发过去（第 0 节+第 2 章 / 第 3–5 章 / 第 6 章 / 第 7–8 章+速查表），先说：

> 我把课程考点资料发给你，请先读一遍并记住，读完只回复"已读完，可以开始出题"，不要总结。

读完后再发：**`现在按你的指令开始工作，先给我菜单`**。

### 备选三：指令框有字数限制

用 `04 单文件整合版.md / .docx`：里面的 **「第一部分｜精简版指令」**（约 1300 字）粘进指令框，**「第二部分｜考点知识库」** 作为第一条消息发给它。

## 📌 考试情报（课件与课程整理）

- **课程范围**：第 2 章 遥感物理基础、第 3 章 传感器（可见光与热红外）、第 4 章 平台与轨道、第 5 章 微波遥感、第 6-0/6-1/6-2/6-3 章 图像处理（基础·辐射校正·几何校正·增强变换）、第 7 章 目视判读、第 8 章 计算机分类。
- **题型（默认模板）**：名词解释 4-6 题（3-5 分）、填空/选择 10-20 题（1-2 分）、简答 3-5 题（5-8 分）、论述/综合 1-2 题（10-15 分）、计算 1-2 题（8-15 分）。**老师给出真实题型时，改 `01` 第 2.2 节那张表即可。**
- **评分规则**：按采分点给分；定义/概念错则该小问后续不给分；计算题只写答案不给公式分、漏单位扣分；论述题缺"优缺点/适用条件/举例"扣分。
- **12 个高频考点**：黑体三定律、大气窗口与散射、地物反射波谱（植被红边）、四类分辨率、真实孔径 vs 合成孔径、雷达三大几何现象、重采样三法、直方图均衡 vs 匹配、NDVI、监督 vs 非监督、混淆矩阵与 Kappa、判读标志八要素。

- 本课课件**从第 2 章开始**（没有第 1 章绪论的 PDF），知识库也从第 2 章起；绪论（遥感定义、发展史、3S 集成）请自行补。
